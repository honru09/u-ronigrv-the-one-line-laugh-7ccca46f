One funny line, any subject, for make.fun's "The One-Line Laugh" bounty. A small Python program writes a single original one-liner (one sentence, under 200 characters) to `entry.txt`. The $5 prize pool is competition-based and goes to the top three lines only — entering does not guarantee any payment.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
cat ./output/entry.txt
```
